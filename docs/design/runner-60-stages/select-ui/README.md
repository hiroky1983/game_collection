## 共通の約束（3 案とも）

- 1 面のマスの見た目は今の `RunnerWorldMap` を踏襲: 世界の色の帯・「4-2」の表記・鍵。**今いる面 = 珊瑚色 + ▶ 今ここ / クリア済み = 薄い世界の色 + ✓ / 未解放 = 灰 + 鍵**。
- 「最高記録」は今の仕様に面ごとの記録が無い（#931 でベストタイムを廃止、記録は到達面）ので、**ノーミスでクリアした面に ★**を付ける案を描いてある。実装するなら `PlayLog` に面ごとの印を足す必要がある（決裁事項）。
- 世界ごとの進み具合は「n / 6」と 6 つの点で出す。

## 3 案の比べ方（要点）

| | A 世界のカード → 中の面 | B 地図と道 | C 世界の帯 |
|---|---|---|---|
| 60 面の見通し | ◎ 10 世界が 1 画面（iPhone 17）。面は 2 段目 | △ 縦に長い（1 世界 190pt × 10 = 約 3 画面分） | ◎ 常に 1 画面。世界はつまみで直接飛べる |
| 今いる面の分かりやすさ | ○ カードの枠 + 顔。面は 2 枚目で | ◎ 道の上に顔。「今いる面へ」で飛べる | ◎ 開いた瞬間に今の世界と面 |
| 操作の手数（遊びたい面まで） | 2 タップ（世界 → 面） | スクロール + 1 タップ | 1 タップ（帯の切り替えが要るときは +1） |
| 「旅」の雰囲気 | ○ 背景の帯で世界が見える | ◎ マリオ型。世界 8〜10 の「続いていく感じ」が出る | ○ 帯 1 枚が大きいので世界の絵は一番よく見える |
| 作り直しの大きさ | 中（画面が 1 枚増える。`GameSetupSheet` の中で 2 段構造） | 大（道の座標・スクロール位置・SE の調整） | 中（横スワイプの帯 + つまみ。既存の 3×2 のマスはそのまま） |
| SE での収まり | 3 段まで。残りはスクロール | 2 世界ちょっと | 収まる（帯 104pt・マス 60pt に縮めてある） |

推し: **C（世界の帯）**。開始シートの「モード → ルール → マップ」の縦の長さが今の最大の問題（マップまで 1 画面スクロール）で、C だけが面数が増えても高さが変わらない。B は見た目の魅力が一番あるが、開始シートの中に入れるには縦に長すぎるので、やるならマップを別画面（ハブからの「ワールドマップ」）に出す形と組み合わせる。
