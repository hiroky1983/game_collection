# おじさんの正面顔（32×30）の検討メモ

会長指摘「おじさんのドットが荒いからデザインしっかりしたいな」（2026-09-17）を受けて、
正面顔を 16×15 → **32×30 ドット**に描き直したときの比較資料。
採用したドットは `Packages/GameKit/Sources/Core/OjisanPixel.swift` にある。ここに置いてあるのは
**採用しなかった案を含む検討の記録**で、アプリのビルドには一切使われない。

## 決まっていること

- 解像度は 32×30（縦横比 16:15 を保った 2 倍）。画面上の大きさは据え置き、表示倍率を半分にして帳尻を合わせた
- `smile`（笑顔）と `cheer`（喜ぶ）はこの版で確定。口ヒゲを薄くして口との間に肌を 1 ドット入れてある
- 土台（輪郭・髪・耳・鼻・頬）は 3 表情で共有し、眉・目・口だけを差し替える

## 決まっていないこと（会長の決裁待ち・ステイ中）

**しかめ面（`frown`）の最終案**。腰痛が限界のときと、チャリンコおじさんのミス時に出る顔なので
「痛い・まいった」に読めないと企画が伝わらない。初版は眉が吊り上がって「怒り」に見えたため描き直し、
今は **F1（食いしばり）が暫定で入っている**。

- `frown-variants.png` — 左から F1（食いしばり・採用中）/ F2（静かに閉じる）/ F3（うっと開ける）
- 社長の所見: F1 は赤帯に白い歯が 3 つ並ぶので遠目に模様に見える。F3 のほうが素直に痛みとして読める

会長は「ちょっと色々プロット作ってみてみたい」とのことだが、fable の週次リミットが近いため
2026-09-17 時点でステイ。再開するときはこの README の続きから。
