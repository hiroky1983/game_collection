# おじさんの衣装別 2D 絵 仕様（ドット絵化の下絵）

refs/heads-3d.png: おじさんの頭の一覧（4方向×7表情、3D）。顔・頭の形・髪・ひげ・耳・鼻はこれに**厳密に合わせる**（同一人物に見えること）。
注意: この一覧の「左」列は顔が画面の右を向き、「右」列は画面の左を向いている。成果物では向きを「画面の右向き / 画面の左向き」で呼ぶ。

## 絵柄（全コマ共通・厳守）
- 2D のアニメ塗り（ベタ塗り＋影1段まで）。グラデーション・ぼかし・光沢・テクスチャ禁止。
- 太めの濃い焦げ茶の縁取り。色数は少なく（1キャラ 16〜20 色程度）。後で 48 ドット高のドット絵に縮めるため、細かい模様・細い線は入れない。
- 頭身は 2.5〜3 頭身のデフォルメ（頭が大きい）。全コマで頭の大きさ・体格・頭身を揃える。
- 背景は単色の白（#FFFFFF）か透明。1 コマ 1 体、周りに余白。影・地面・効果線は描かない（汗・痛みマーク・音符などの記号は可）。

## 衣装 A: 作業服（ゲーム「腰痛おじさんパズル」。重い荷物を運んで腰を痛める）
- 服装: 紺〜灰色の作業着（上着）、作業ズボン、軍手、安全靴。頭に白いタオルを巻くか、黄色いヘルメット（どちらか一方に統一）。
- コマ（表情は refs の表情名を使う）:
  1. 立ち 4 方向（前・画面右向き・画面左向き・後ろ）表情=真顔（後ろは表情なし）
  2. 段ボールを持つ・軽い（画面右向き・笑顔）
  3. 段ボールを持つ・重い（画面右向き・痛い、汗）
  4. 限界: 荷物を置いて腰を押さえる（画面右向き・痛い、痛みマーク）
  5. 倒れる: うつ伏せに倒れ荷物が転がる（泣いてる）

## 衣装 B: 和の着物（ゲーム「盆栽を合体させて育てる落ちものパズル」）
- 服装: 落ち着いた色（深緑か藍）の着物＋羽織、帯、足袋と草履。
- コマ:
  1. 立ち 4 方向（前・画面右向き・画面左向き・後ろ）表情=真顔
  2. 盆栽の鉢を両手で持って眺める（前・笑顔）
  3. はさみで剪定する（画面右向き・真顔）
  4. 大喜び（前・笑顔、両手を上げる）
  5. がっかり（前・泣いてる、肩を落とす）
