加工の手順（実装 PR・2026-10-17）:

1. 透明の余白を切り落とす（絵の下端 = 鉢の底。盤では鉢の底を当たり判定の円の下端に合わせる）。
2. 長辺を「半径 × 36px」（盤の幅 400pt・3x の画面で絵の枠＝直径の 1.3 倍を描くのに足りる大きさ）まで縮める。
   元が小さい 6〜11 段は縮めない（元の解像度のまま）。
3. 256 色の減色（Pillow の FASTOCTREE・誤差拡散）で保存。見た目の差はほぼ無く、11 枚で約 1.4MB → 約 290KB。
