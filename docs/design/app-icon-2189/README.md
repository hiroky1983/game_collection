# アプリアイコン刷新（#2189）の出所と作業記録

Issue #2189「[v1.1.12] アプリアイコンの刷新」。会長が ChatGPT で作成した新アイコン画像を 1024×1024 化し、
`App/Assets.xcassets/AppIcon.appiconset/AppIcon.png` に差し替えた作業の記録。

## 1. 経緯

- 2026-10-13: 会長指示「アイコンの刷新も入れといて欲しい」（v1.1.12 に入れる）。当初は社長がモックを作る想定だった。
- 2026-10-12: 会長指示で方針変更。**アイコンは会長が ChatGPT で作る。社長はモックを作らない。** 社長側は画像を
  受け取ってからの各サイズ書き出し・アプリへの組み込み・出所の docs 記録を担当する。
- 2026-10-14: 会長決定。モチーフは「おじさんと猫を中心に、麻雀牌・トランプとチップ・オセロ・将棋の駒・2048・
  ナンプレ・ブロック・ジグソーを周りに配置」した構図。原画を受け取り、このディレクトリに記録した。

## 2. 素材

| ファイル | 内容 |
|---|---|
| `source.png` | 会長が ChatGPT で作成した原画。1254×1254・透過なし・RGB。絵の中身（構図・描き足し・切り抜き）は変更していない。 |
| `AppIcon-1024.png` | `source.png` を Lanczos 法で 1024×1024 に高品質縮小し、sRGB プロファイルを明示的に埋め込んだもの（透過なし）。アプリに組み込んだものと同一。 |
| `preview_montage.png` | 180 / 120 / 80 / 58 / 40px（ホーム画面・設定・通知相当のサイズ）に縮小したプレビューを並べた確認用画像。 |

変換は単純なリサイズのみで、新規の描き足し・構図変更・色調整は行っていない。

## 3. 既存アイコンの形式との整合

`App/Assets.xcassets/AppIcon.appiconset/Contents.json` は `idiom: universal` の 1024×1024 単一画像のみを
参照する形式（ダーク版・着色版（tinted）の枠は存在しない）。今回もこの形式をそのまま踏襲し、同じ 1 枚
（`AppIcon.png`）を差し替えるだけで対応した。ダーク/着色版の追加は行っていない（既存の扱いに合わせた判断）。

## 4. 小さいサイズでの見え方（所見・未対応）

`preview_montage.png` を目視確認した所見。会長決定事項のため直しはせず記録のみ。

- 180px・120px（ホーム画面相当）では、おじさんと猫の表情、麻雀牌の「中」「發」、将棋の「王将」等はまだ判読できる。
- 80px（設定相当）以下になると、麻雀牌・トランプ・オセロ・将棋駒・数字パズル・ブロック・ジグソーなど周囲の
  要素はほぼ色の塊としてしか見えず、個々のモチーフは判別できない。
- 58px・40px（設定2x・通知相当）では、将棋駒やトランプの文字・数字パズルの数字は完全に潰れて読めない。
  画面全体が「賑やかな色面」として視認される状態で、個々の要素よりも中央のおじさん＋猫のシルエットが
  かろうじて視認の手がかりになっている。
- 背景の桜・光の演出（スパークル）が全体のコントラストを下げており、小サイズでは主役（おじさん・猫）の
  輪郭がやや埋もれて見える。
- 全体に要素数が多く「余白」が少ないため、ホーム画面の他アプリのアイコン（単純な図形・ロゴが多い）と
  並べたときに視認性で不利になりうる。

## 5. 出所・利用条件

会長が自身の ChatGPT アカウントで画像生成して作成した。ChatGPT の画像生成は OpenAI の
[Terms of Use](https://openai.com/policies/row-terms-of-use/) の対象で、Ownership of content の条項により
出力（Output）の権利は利用者（会長）に帰属する。商用利用の制限・表示義務の条文は無く、アプリアイコン・
ストア掲載物に利用してよい（`docs/design/ojisan-pixel-pipeline/README.md` の確認結果と同じ扱い）。

注意点も同様に引き継ぐ: 既存の作品・商標に類似した場合の責任は利用者側（個人向け規約に OpenAI の補償は無い）。
生成画像には C2PA / SynthID の来歴情報が含まれる。
