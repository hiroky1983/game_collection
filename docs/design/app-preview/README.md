## モックの構成（ffmpeg 版 `preview_ffmpeg.mp4`）

実機録画クリップ 6 本を等倍で連結し、下部バナーに文字を重ねている。クリップの並び順と秒数（連結後のタイムライン基準）:

| 区間 | ゲーム | 長さ |
| --- | --- | --- |
| 0.0–8.9s | 柵越えおじさん（ホームラン） | 8.9 秒 |
| 8.9–12.9s | オセロ | 4.0 秒 |
| 12.9–16.9s | 将棋 | 4.0 秒 |
| 16.9–20.9s | ポーカー | 4.0 秒 |
| 20.9–24.9s | 2048 | 4.0 秒 |
| 24.9–28.9s | チャリンコおじさん（ランナー） | 4.0 秒 |

下部バナーのテキスト（`tel/` 配下の `.txt` を drawtext で合成、ここでは本 PR には含めていない）:

- 0.3–8.9s: 「新作」「柵越えおじさん」
- 8.9–16.9s: 「将棋・オセロ・麻雀…」
- 16.9–24.9s: 「トランプもパズルも」「20本以上」
- 24.9–29s: バナー色がオレンジに切り替わり「あそびば」「勝手に出る全画面広告なし」

Canva 版（`preview_canva.mp4`）は同じ素材セットを Canva 上で手動編集・書き出したもので、ffmpeg 版と同一の再現スクリプトは無い（Canva のプロジェクトファイル・編集手順はこの PR には保存していない）。

## `build_ffmpeg.sh` について（参考・そのままでは動かない）

- スクリプト内の `S=/private/tmp/claude-501/.../scratchpad/preview-video` はこの PR を作成したセッションのスクラッチパスへの絶対パス参照で、**セッション終了後は存在しない**。再利用する場合は `S`（素材一式のディレクトリ）と `C`/`T`（`clips/`・テキスト/フォント素材の `tel/`）を自分の環境のパスに書き換える必要がある。
- `clips/preview-clip-N-*.mp4`（録画済みクリップ 6 本）・`tel/font.ttc`・`tel/t*.txt`（テキスト素材）が別途必要。いずれも一時領域にのみ存在し、本 PR には含めていない。
- 内容を確認した限り、API キー・トークン等の秘密情報は含まれていない（ffmpeg/ffprobe のローカルコマンドのみ）。
