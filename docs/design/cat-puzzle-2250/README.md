# 「おじさんの飼い猫パズル」（#2250）の見た目のモック

issue #2250（企画倉庫）の検討用。会長指示「決めることは無しで、とにかくモックを作ってくれ」（2026-10-14）を受けて、
社長が案を決めて作った **見た目の案** 一式。**アプリのコードは変えていない**。名前は仮で「おじさんの飼い猫」。

遊び方（共通）: 色分けした区画に猫を 1 匹ずつ。各行・各列にも 1 匹ずつ。猫どうしは隣り合わない（斜めも）。
置いた猫から機械的に決まるマスには × を付けて消していく。

## 画面の作り（既存ゲームに揃えた点）

- ヘッダー: 戻る（<）・題・「？」（遊び方）・「＋」（新規）の並びは `Core/GameChrome.swift` の共通の並びどおり
- 題の下の帯: ナンプレと同じ白い帯。左に「残り n 匹」、右に「ミス・難易度・タイム」
- 盤の下の「操作の段」: `Core/GameActionRow.swift`（#1834 案A・会長決裁 2026-10-06）の形。広告が絡む「戻す」「ヒント（あと n 回）」を段に、
  やり直し・諦めるなどは「⋯」に入れる前提
- クリアのカード: `Core/GameClearCard.swift` と同じ要素（トロフィー・「クリア！」・記録の行・「盤を見る」）。
  モックでは猫がくつろぐ絵を隠さないよう **盤の下** に描いたが、実装では他ゲームと同じく盤に重ねる
- 画面下の灰色はバナー広告の枠（仮・高さ 50pt）
- 配色は `Core/Theme.swift`（地 `#FFF6EC`・文字 `#4A3B33`・coral / teal / yellow）

## 使った盤（7×7・解は 1 つ）

`tools/gen3.py`（山登りで区画を直して解を 1 つにする生成器）の seed 1。案A・案B とも同じ盤。
`tools/build.py` が組み立て時に解の数を数え直し、1 つでなければ止まる。

```
区画（数字が区画の番号）        答え（行→列）: [1, 5, 2, 4, 6, 0, 3]
0 0 0 0 0 1 1                 行0: 列1（区画0・こたつ）
0 0 0 0 0 1 1                 行1: 列5（区画1・押し入れ）
0 0 2 1 1 1 1                 行2: 列2（区画2・段ボール）
0 2 2 2 3 3 1                 行3: 列4（区画3・本棚）
2 2 5 2 3 3 4                 行4: 列6（区画4・お風呂）
5 2 5 5 6 3 4                 行5: 列0（区画5・台所）
5 5 5 6 6 6 4                 行6: 列3（区画6・玄関）
```

案B の「にゃー」のマス（答えのマスではない）と、その周囲 8 マスにいる猫の数:
(行0,列3)=0「しーん」・(行2,列4)=2・(行4,列5)=2・(行5,列2)=1。

案A の遊んでいる途中（a1）は (0,1)(1,5)(5,0) に猫を置いた状態、案B（b1）は (1,5)(3,4)。× は置いた猫と同じ行・列・区画と周囲 8 マスに機械的に付けている。

## 猫の絵の出所

`assets/cats/*.png` は、**会長が ChatGPT で作成した猫（グレーと白のハチワレ・赤い首輪に金の鈴）の表情・ポーズのシート**
（2026-10-14 受領。新アプリアイコン #2189 と同じキャラ）から `tools/crop_cats.py` で切り抜いたもの。
白背景を外周から塗りつぶして透過にしただけで、描き足し・色の変更はしていない（隣の猫のひげの切れ端が少し残る）。
利用条件は `docs/design/app-icon-2189/README.md` §5 と同じ（ChatGPT の出力の権利は会長に帰属・商用可）。
元のシートそのものはこのディレクトリには置いていない。

おじさん（`assets/ojisan_cheer.png`）はハブ刷新モックの `hub-redesign-1831/hub-redesign/assets/sprites/ojisan_cheer.png` のコピー（アプリ内のドット絵）。

他社の画像・他社アプリの画面は参照も使用もしていない。盤の塗り・こたつ・浴槽などの小物はすべて CSS で描いた。

## 再生成

```bash
# 切り抜き（会長のシートが要る）
python3 docs/design/cat-puzzle-2250/tools/crop_cats.py <sheet.png> docs/design/cat-puzzle-2250/tools/cats
# 組み立てと PNG 化（Google Chrome のヘッドレスを使う）
python3 docs/design/cat-puzzle-2250/tools/build.py docs/design/cat-puzzle-2250
```

`build.py` は隣に `cats/` があればそこから `assets/cats/` へコピーし、無ければ既にある `assets/cats/` をそのまま使う。

## 社長の所見（決裁は会長）

- **推すのは案A「おじさんの家」**。区画を部屋・家具に見立てるだけでルールの説明が要らなくなり（「家のどこかに 7 匹いる」）、
  クリアの絵（それぞれの場所でくつろぐ）が毎回のご褒美になる。猫のシートのポーズ（寝る・箱に入る・伸び）がそのまま活きる。
- 案B「鳴き声さがし」は推理の手がかりが増えて解きごたえが出るが、Queens 型の「区画だけで解ける」潔さが薄れ、
  画面も情報が多くなる。**案A の上級の難易度（むずかしい）だけに足す**のが落としどころと考える。
- 盤の大きさは 7×7 を基準に、かんたん 6×6・むずかしい 8×8 を想定（8×8 は 1 マス 45pt でまだ押せる）。
- 未決のまま残す点: 名前（仮）・おじさんの役回りの話の付け方・出す版。
