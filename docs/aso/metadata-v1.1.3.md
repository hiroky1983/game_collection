### 3-0. この枠に何を置くかの原則（v1.1.1 §3-0 のまま）

日本ストアのキーワード枠は2つある（1枠目 = 日本語ロケール = **この欄**、2枠目 = 英語(U.S.) ロケール =
[`keywords-cross-localization-v1.1.1.md`](keywords-cross-localization-v1.1.1.md)）。2枠目は
**#171 の ASC 操作（英語(U.S.) ロケールの追加）が済んで初めて生える**もので、**2026-09-07 時点で未実現**
（#171 は `blocked` 継続）。

→ **収録ゲームの正式名は必ず1枠目に置く。** 2枠目が生えなかった場合でも取りこぼさないため。
別名・一般語・属性語は2枠目に寄せる。**v1.1.3 でもこの原則がそのまま効いており**、
`ソリティア`（中央値102,857 = 順位は狙えない）を入れているのはこの原則によるもので、
順位を期待しているからではない（§3-6）。

### 3-1〜3-5（v1.1.1 パックの設計。ここでは変更していない）

取捨選択の原則（タイトル・サブタイトルとの重複排除／タイトルから降ろした語の回収／別名の回収／
未実装のゲーム名は入れない／他社アプリ名は不採用）は **`metadata-v1.1.1.md` §3-1〜§3-5 のまま**。
本パックの変更は §3-6 の1点だけ。

|---|---|---|---|
| `trackName`（タイトル） | `あそびば：将棋 オセロ 2048 マインスイーパー` | `あそびば：神経衰弱 マインスイーパー 五目並べ 将棋` | ❌ **v1.1.0 パック §1 のまま** |
| `description` 冒頭 | `【あそびばの特徴】` から始まる（**§4-a の冒頭3行が無い**） | §4-a の3行を先頭に置く | ❌ |

**読み取れること**:

1. **文言パックを書いても、ASC に入るかは別**である。v1.1.1 の入稿では**説明文の一部だけが反映され、
   タイトル（§1）と説明文の冒頭3行（§4-a）は入らなかった**。
2. したがって **#471 の起票時の前提（「ストア文言が12本前提のまま」）は半分だけ正しい**。
   説明文は12本に是正されているが、**タイトルは8ゲーム時代（v1.1.0）のまま**で、より古い。
3. `詰め合わせ` の3位（§1）が**サブタイトル由来かキーワード欄由来かは特定できない**。
   v1.1.0 のサブタイトル（`定番ゲーム8種の詰め合わせ`）と v1.1.1 パック §3 のキーワード欄の
   **両方**にこの語があり、どちらがストアに入っているかを AI 側から読む手段が無いため。

**対策**: §8 に「**入稿後に iTunes Lookup API で `trackName` と `description` を突き合わせる**」関所を足した。
AI 側から検証できるのはこの2フィールドだけなので、サブタイトル・キーワードは会長の目視確認に頼る。

### 5-c（v1.1.1 から継続）「日本製」→ 条件付きで採用（**会長の1点確認が要る唯一の訴求**）

`sellerName` / `artistName` = `hiroki yamada` は**表示名にすぎず**、開発者の所在地・法的販売者の証明にはならない。
AI 側からは ASC アカウントの所在地を読めない（会長の職掌）。**確認が取れるまで断定しない**扱いを引き継ぐ:

- **入稿時に会長が確認する**（§8 の関所）: ASC のアカウント所在地／法的住所が日本であること。
- **取れない・自信が持てない場合の差し替え文言**:
  - 説明文の冒頭1行目: `日本製のゲーム詰め合わせアプリ。` → `日本語で作られたゲーム詰め合わせアプリ。`
  - プロモーションテキストの冒頭: `日本製のゲーム詰め合わせ。` → `日本語で作られたゲーム詰め合わせ。`
    （**165字**。上限170字に収まることを実測済み）
  - キーワード欄: `日本製` を削る。**空いた4字（カンマ込み）に入れる語は §3-6 の削除候補表の逆順**で、
    第一候補は `対戦`（`,対戦` = 3字。99 - 4 + 3 = **98字**）。

## 6. プロモーションテキスト（170字以内・審査なしで差し替え可能）

```text
日本製のゲーム詰め合わせ。将棋・オセロ・囲碁・チェス・五目並べ・2048・マインスイーパー・ポーカー・神経衰弱・ブラックジャック・大富豪・ソリティア・麻雀ソリティア・麻雀（四人打ち）・ナンプレ・ブロック崩しの16本を収録。通信不要のオフライン対応。全画面広告が勝手に割り込むことはなく、中断しても「続きから」再開できます。
```

**161/170字**（§5-c の差し替え文言を使う場合は **165字**。どちらも上限内）。

- **v1.1.1 の 150字から +11字**。内訳は「列挙に4本足す **+20字**」と「末尾2文を1文にまとめる **-9字**」で、
  足しただけの形（v1.1.1 の言い回しのまま16本にしたもの）は **170字**とちょうど上限で余白が無くなる。
  §5-c の差し替え（`日本製` → `日本語で作られた`・+4字）を使うと **174字**で上限を超えてしまうため、
  v1.1.1 の「通信不要のオフライン対応**で、プレイ中に**全画面広告が勝手に割り込む**ことはありません**。
  **中断しても**「続きから」再開できます。」を1文にまとめて余白を作った。

  > **v1.1.1 §6 の自称「148/170字」は誤り**で、実測は **150字**（`/usr/bin/python3` の `len()`）。
  > 上限内なので入稿には影響しないが、差分の基準値になるのでここで訂正しておく。
- **`勝手に` の修飾語は残してある**（§5-h の ⚠️。落とすと虚偽になる）。
- 説明文（§4-a）と違い**`ソリティア` に `（クロンダイク）` を添えていない**。
  添えると178字で上限を超えるため。プロモーションテキストは**審査なしでいつでも差し替え可能**な欄なので、
  文字数の制約を優先した。
