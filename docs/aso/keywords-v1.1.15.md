# App Store 入稿パック（v1.1.15 / 日本語 ja・キーワード欄）

カスタムプロダクトページ（CPP）第 2 弾（#2995）のために、ja のキーワード欄を入れ替える案。**入稿は v1.1.15 の提出前に社長が ASC API で入れる**
（この資料は入れる値の正典。ASC の操作は当番では行わない）。タイトル・サブタイトル・説明文は v1.1.14 のまま（`metadata-v1.1.14.md`）。

## 0. 方針

- 会長方針（2026-10-25）: 定番ゲームは段階的に 1 本ずつ CPP を作る。第 2 弾は **オセロ・麻雀ソリティア・ナンプレ** の 3 本。
- CPP に割り当てられるのは**キーワード欄（ja）の語だけ**。オセロは既に欄にある。麻雀ソリティア・ナンプレは v1.1.14 の組み直し（#2053）で欄から外したので、戻す。
- 欄は 94/100 字で、2 語を足すと 106 字になるため、順位の低い語を外す。

## 1. 入れ替える語（順位は 2026-10-27 の日次取得・Search API の近似値）

| | 語 | 順位 | 理由 |
|---|---|---|---|
| 足す | ナンプレ | 圏外 | CPP 第 2 弾の対象。CPP は語の検索結果に出る順位ではなく、その語で来た人に見せる商品ページを替える仕組み |
| 足す | 麻雀ソリティア | 圏外（10-26 のみ 60 位） | 同上 |
| 外す | ハーツ | 134 位 | 100 位以内に入っていない。字数 4（カンマ込み） |
| 外す | 花札 | 102 位 | 同上。「こいこい」（69 位）が残るので花札こいこいの入口は消えない。字数 3（カンマ込み） |

外す 2 語はキーワード欄の中で順位が最も低い取れている語（圏外の 神経衰弱・野球・麻雀 は、柵越えおじさんの入口の試行（野球）・麻雀のタイトル→欄への移し替え（麻雀、会長決裁 2026-10-24）・
神経衰弱の取り込み途中のため、今回は触らない）。大富豪・ソリティア・将棋は既存の CPP の割り当て先なので外さない。

## 2. 入れるキーワード（100字以内）

```text
ブラックジャック,五目並べ,オセロ,こいこい,神経衰弱,スピード,フリーセル,スパイダー,麻雀,野球,一人用,通信不要,続きから,詰め合わせ,日本製,大富豪,ソリティア,将棋,ナンプレ,麻雀ソリティア
```

100/100 字（v1.1.14 の 94 字から ハーツ・花札 を外し ナンプレ・麻雀ソリティア を足した。`len()` で数えた）。賭けを連想させる語・他社の商標名は含まない。

## 3. 順位の取得対象

`docs/aso/keywords-current.txt` の語は変えない（ナンプレ・麻雀ソリティアは既に対象。ハーツ・花札は欄から外れても「記録対象を増やす」の一覧（#2053）に残し、推移を見続ける）。

## 4. 手順（社長）

1. v1.1.15 の提出前に、ASC API で ja のキーワードを §2 に入れ、GET で読み直して一致を確認する。
2. 公開後（App Store の公開版が 1.1.15 になってから）、CPP を 3 本作り（オセロ・麻雀ソリティア・ナンプレ）、キーワードを割り当てる。割り当てられる語は公開中の版の欄に限られる。
3. スクショは build 確定後の画面で撮る（#2083 の方針）。
