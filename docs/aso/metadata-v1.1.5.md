### 差し替えた1枚とその理由（`05-solitaire` → `05-runner`）

**外したのは `05-solitaire`（ソリティア）**。3つの実測が揃ったため:

1. **ハブの1枚目に名前・アイコン・説明つきで写る**（`01-hub.png`）。個別枠が無くても商品ページから消えない。
   一方**チャリンコおじさんはハブの19番目**で、スクロールしないと出てこない。
2. **`ソリティア` は検索順位が取れない語**（2026-09-16 実測: **圏外**・タイトル一致113件）。
   §3 でもキーワード欄から外した。枠を1つ使って個別に訴求する費用対効果が20本中いちばん低い。
3. **同系統が3本に増えた**（ソリティア・フリーセル・スパイダーソリティア）。絵が似ており、
   10枠のなかでは重複に近い。ソリティア系は `18`〜`20` の控えに揃えてある。

**入れたのはチャリンコおじさん**。v1.1.5 の最大の変更（マージ済み PR 130本の最大の塊）でありながら、
**入稿する10枚に1枚も入っていなかった**。20本のうち**動きのある絵はこの1本だけ**で、
盤・カードが並ぶ商品ページの中で最も目を引く。

**どの画にするかは `-simulateRunner` のシナリオを20枚ほど撮って見比べて決めた**（下表は代表的な6つ）:
