## 3. キーワードフィールド（100字以内・カンマ区切り・スペースなし）

> ⚠️ **`リバーシ` は使用禁止**（Apple 審査却下 5.2.1・Ravensburger の商標。2026-08-27 にキーワード欄、
> 2026-08-28 に説明文の残存分を ASC から削除済み。詳細は `metadata-v1.1.1.md` §3 冒頭）。
> 以下は削除反映後の現行入稿値。

```text
五目並べ,神経衰弱,ブラックジャック,ポーカー,連珠,地雷,トランプ,ボード,テーブル,暇つぶし,無料,一人用,CPU,対戦,脳トレ,パズル,ミニ,記憶力,カード,無課金,通信不要,軽い
```

93/100**字**。設計方針:

- タイトル・サブタイトルに入れた語は**すべて除外**（Apple の検索は同じ語を複数フィールドに入れても加点しない）。
- `連珠`（五目並べの正式名）・`地雷`（マインスイーパー）で別名検索を回収。
- 他社アプリ名（将皇・ぴよ将棋など）は審査・法務リスクのため意図的に不採用。
- 収録していないゲーム名（ソリティア・麻雀など）は入れない（誤誘導は審査指摘の対象）。

**入稿時に確認してほしいこと（上限の単位）**: この欄の上限は Apple の表記では「100 characters」で、
App Store Connect の入力欄も**文字数**でカウントする（日本語の全角1字＝1カウント）という理解で上の案を作った。
ただし「100 バイト」と説明している資料もあり、AI からは実際の入力欄を確認できない。
**貼り付けたときに ASC が上限超過を出したら**、代わりに下のバイト数版（78バイト・30字）を使ってほしい。

```text
五目並べ,神経衰弱,暇つぶし,脳トレ,トランプ,一人用,無料
```

削る優先順位は「別名で拾える語（連珠・地雷）→ 一般語（ボード・テーブル・パズル・カード）→ 属性語（無課金・通信不要・軽い）」の順。
上の7語は、説明文・タイトル・サブタイトルのどこにも入っていない＝**この欄でしか拾えない語**だけを残したもの。

## 4. 説明文（全文・そのまま貼り替え）

```text
8つの定番ゲームがこれ1本。通信不要のオフライン対応で、アカウント登録もいりません。

将棋・オセロ・五目並べ・2048・マインスイーパー・ポーカー・神経衰弱・ブラックジャックを収録。
通勤中や待ち時間、電波の届かない場所でも、開いてすぐ遊べます。

【あそびばの特徴】

■ 通信不要・オフラインで遊べる
機内モードでも地下鉄でも、8つのゲームすべてが最後まで遊べます。

■ 無料・アカウント登録なし
会員登録もログインも不要。ダウンロードしたらすぐ始められます（広告表示あり）。

■ 中断しても「続きから」
途中でアプリを閉じても、次に開いたときに同じ場面から続けられます。一覧に「続きから」と表示されるので、どのゲームを途中でやめたか一目で分かります。

■ CPU対戦
将棋・オセロ・五目並べ・神経衰弱は CPU と対戦できます。ポーカー・ブラックジャックは CPU／ディーラーが相手です。
将棋・オセロ・五目並べ・神経衰弱には1手戻せる「待った」があります（無料の回数を使い切った後は広告の視聴で追加できます）。

■ 自分専用に並べ替え
よく遊ぶゲームを上に、遊ばないゲームは非表示に。設定から自由に並べ替えられます。

【収録ゲーム】

▼ 将棋
本格的な CPU と対局できる将棋。持ち駒・成り・詰みまで実装した本格ルールで、初心者から上級者まで楽しめます。

▼ オセロ
石を挟んでひっくり返す定番ボードゲーム。CPU と1対1で対戦できます。

▼ 五目並べ（連珠）
先に5つ並べた方が勝ち。15路盤でCPUに挑戦できます。

▼ 2048
タイルをスワイプで合体させ、2048を目指す数字パズル。スコアが伸びていく手触りがくせになります。

▼ マインスイーパー
数字を手がかりに地雷を避けて全マスを開けるパズル。旗を立てて地雷の位置を管理できます。

▼ ポーカー
5枚引き（ドロー）ポーカー。カードを交換して役を作り、チップを賭けて CPU と勝負します。

▼ 神経衰弱
カードをめくってペアを揃える記憶力ゲーム。CPU と得点を取り合います。

▼ ブラックジャック
21を超えないようカードを引き、ディーラーに勝つカードゲーム。

【こんなときに】
・電車やバスでの移動中、電波が不安定な場所での暇つぶしに
・1日5分、頭の体操・脳トレに
・将棋やオセロを久しぶりに指したくなったときに

ポーカーの役は、アプリ内の役一覧でいつでも確認できます。
```

補足（**会長の確認事項**）: アプリサイズを数値で訴求すると強い差別化になるが（v1.0.2 は 4.6MB）、
v1.1.0 は Firebase SDK の追加でサイズが増える見込みのため、**この説明文には数値を入れていない**。
TestFlight のビルドサイズを見て 10MB 未満に収まっていれば、冒頭に「アプリは約○MB と軽量」を1行足すと効く。
