## App description (English, summary)

```
Asobiba is a Japanese-made offline game collection app for iOS, bundling 20 classic and
original games — Shogi, Othello, Go, Chess, 2048, Minesweeper, Poker, Blackjack, Daifugo,
4-player Mahjong, Hanafuda Koi-Koi, several Solitaire variants, Sudoku, Breakout, and an
original bicycle-runner action game. No internet, no account, and no forced full-screen ads.
v1.1.5 rebuilds the runner game from the ground up and adds two new games.
```
