## 4. 説明文

```text
日本製のゲーム詰め合わせアプリ。大富豪・ババ抜き・ハーツ・スピード・ブラックジャック・ポーカー・神経衰弱・花札こいこい・カードしりとり・ソリティア（クロンダイク）・フリーセル・スパイダーソリティアのトランプと、将棋・オセロ・囲碁・チェス・五目並べ・麻雀ソリティア・麻雀（四人打ち）・ナンプレ・15パズル・2048・マインスイーパー・ブロック崩し・チャリンコおじさん・柵越えおじさん・おじさんの荷物運びパズル・ぱっと暗算・いろリレー・おじさんの盆栽・サイコロ役づくり・おじさんちのねこさがしの32本を収録しています。
プレイ中に全画面広告が勝手に割り込むことはありません。
通信不要のオフライン対応。機内モードでも地下鉄でも、32本すべてが最後まで遊べます。

【あそびばの特徴】

■ 通信不要・オフラインで遊べる
機内モードでも地下鉄でも、32本のゲームすべてが最後まで遊べます。

■ 無料・アカウント登録なし・広告の割り込みなし
会員登録もログインも不要。ダウンロードしたらすぐ始められます。プレイの途中に全画面広告が勝手に割り込むことはありません。全画面の動画広告が流れるのは「待った」を追加するときなど、あなたが自分で「見る」を選んだときだけです。

■ 中断しても「続きから」
途中でアプリを閉じても、次に開いたときに同じ場面から続けられます。一覧に「続きから」と表示されるので、どのゲームを途中でやめたか一目で分かります。

■ 自己ベストは「きろく」画面にまとまります
全ゲームの自己ベスト・勝敗・連勝を1画面で見られます。勝ちが続いたら、次の難易度もおすすめします。

■ CPU対戦
将棋・オセロ・囲碁・チェス・五目並べ・神経衰弱・花札こいこい・カードしりとり・スピードは CPU と1対1で、大富豪・ババ抜き・ハーツ・麻雀（四人打ち）・いろリレーは CPU 3人と対戦できます。ポーカー・ブラックジャックは CPU／ディーラーと勝負します。ソリティア・フリーセル・スパイダーソリティア・麻雀ソリティア・ナンプレ・2048・マインスイーパー・ブロック崩し・15パズル・チャリンコおじさん・柵越えおじさん・おじさんの荷物運びパズル・ぱっと暗算・おじさんの盆栽・サイコロ役づくり・おじさんちのねこさがしは1人でじっくり遊べます。

■ Game Center 対応
タイムやスコアの世界ランキングと実績に対応。自己ベストを世界中のプレイヤーと比べられます。

■ 自分専用に並べ替え
よく遊ぶゲームを上に、遊ばないゲームは非表示に。設定から自由に並べ替えられます。

【収録ゲーム】

▼ 大富豪
CPU 3人との4人戦。革命・8切りなどの定番ルールと、順位に応じたカード交換で、大富豪の座を守り合います。

▼ ババ抜き
CPU 3人と遊ぶ4人のババ抜き。となりの CPU の伏せた札を1枚ずつ引き、最後にジョーカーを持って残った人が負けです。札を選ぶと、ジョーカーを持つ CPU は顔に出ることがあります。CPU の強さは4段階。

▼ ハーツ
CPU 3人と遊ぶ4人のハーツ。出された札と同じスートを順に出し、いちばん大きい札を出した人が4枚を取ります。ハートは1枚1点、スペードの Q は13点で、だれかが50点に届いたとき合計の少ない人が勝ち。CPU の強さは4段階。

▼ スピード
真ん中の2つの台札に、数字が1つ違いの札を CPU より先に重ねていく1対1のトランプゲーム。順番はなく、CPU も同時に出してきます。CPU の速さは「ゆっくり」「ふつう」「はやい」の3段階で、あなたの側に制限時間はありません。

▼ ブラックジャック
21を超えないようカードを引き、ディーラーに勝つカードゲーム。10・J・Q・K の同じ10値同士でもスプリットできます。

▼ ポーカー
5枚引き（ドロー）ポーカー。カードを交換して役を作り、CPU との10回勝負で役の点数を競います。

▼ 神経衰弱
カードをめくってペアを揃える定番ゲーム。CPU と記憶力を競り合います。

▼ 花札こいこい
手札と場の札を同じ月で合わせ、役を作って得点します。「こいこい」で続ければ得点は倍に、相手に先に上がられたら0点。引き際の読み合いが勝負どころです。

▼ カードしりとり
場に並んだ絵札から、しりとりでつながる1枚を CPU と取り合うカードゲーム。決められた枚数を先に取れば勝ちですが、時間切れは負けなので駆け引きが要ります。

▼ ソリティア（クロンダイク）
52枚を組札に積み上げる定番の1人用トランプ。山札を1枚ずつめくるか3枚ずつめくるかを選べます。

▼ フリーセル
52枚すべてが最初から見えているソリティア。出題されるのは解けることを確認済みの配札だけなので、運ではなく読みだけで決まります。札を大きく表示する拡大モードにも対応。

▼ スパイダーソリティア
2組104枚を、同じスートでK→Aの並びに揃えて取り除いていきます。1スート・2スート・4スートの3段階で、初めての方から歯ごたえを求める方まで遊べます。

▼ 将棋
本格的な CPU と対局できる将棋。持ち駒・成り・詰みまで実装した本格ルールです。

▼ オセロ
石を挟んでひっくり返す定番ボードゲーム。角を取り合う読み合いを CPU と楽しめます。

▼ 囲碁
9路盤で CPU と対局できる囲碁。中国ルールの面積計算で勝敗を決め、置き石でハンデもつけられます。アプリ内でルールも読めます。

▼ チェス
CPU と対局できる本格チェス。キャスリング・アンパッサン・プロモーションまで対応し、駒の意匠は「立体」「チープ」から選べます。

▼ 五目並べ（連珠）
先に5つ並べた方が勝ち。15路盤でCPUに挑戦できます。

▼ 麻雀（四人打ち）
CPU 3人との東風戦。ポン・チー・カン・立直から点数計算まで実装した本格ルールです。短い一局戦も選べます。

▼ 麻雀ソリティア
積み上げた麻雀牌から同じ絵柄の牌を2枚ずつ取り除いていく定番の1人用パズル。ヒントと並べ替えで手詰まりからも立て直せます。

▼ ナンプレ
9×9のマスに1〜9を埋める定番パズル。かんたん・ふつう・むずかしいの3段階で、出題は必ず答えが1通りに決まります。メモとヒント付き。

▼ 15パズル
空いたマスへ数字をスライドさせて1〜15の順に並べる定番パズル。出題は必ず解ける配置で、最少手数の記録に挑戦できます。

▼ 2048
タイルをスワイプで合体させ、2048を目指すパズル。数字が伸びていく手触りがくせになります。

▼ マインスイーパー
数字を手がかりに地雷を避けてマスを開くパズル。フラグを立てて地雷の位置を管理できます。

▼ ブロック崩し
パドルではね返してブロックを全部くずすアクション。バーが伸びる・ボールが増えるなどのパワーアップアイテムで逆転も狙えます。

▼ チャリンコおじさん
タップで跳んで走り抜ける横スクロールアクション。朝の下町から温泉街まで7つの世界・全42ステージを、風に飛ばされた宝くじを追いかけて走ります。穴や岩に加えて、飛び立つ鳥・向かってくる犬・突進するイノシシが行く手をふさぎ、たこ焼きを取れば少しのあいだ無敵。終わりのないエンドレスモードもあります。

▼ 柵越えおじさん
マシンが投げる球を打ち返して、柵越えの本数と飛距離を競うホームラン競争。1日3回まで無料で挑戦でき、0:00に回数が戻ります。回数を使い切っても、広告を見ればもう1回遊べます。週間ランキングにも参加できます（Game Center）。

▼ おじさんの荷物運びパズル
おじさんが運ぶ荷物を2個1組で積んでいく、6列×12段の一人用パズル。同じ荷物が4つ以上つながると消え、続けて消えれば連鎖になります。荷物を置くたびに腰痛ゲージが溜まり、100で入院します。

▼ ぱっと暗算
数が1つずつパッと出ては消えるので、頭の中でぜんぶ足して合計をテンキーで答える一人用の暗算ゲーム。桁数・個数・速さをそれぞれ選べて、1桁・5個のやさしい問題から始められます。正解が続くほど連続正解が伸び、回答の速さも記録に残ります。

▼ いろリレー
場の札と同じ色か、同じ数字・記号の札を出していき、先に手札をなくした人が勝ちのカードゲーム。CPU 3人との4人対戦で、とばし・ぎゃく・+2・いろがえ・いろがえ+4の特殊札で流れが変わります。出せる札がなければ山から1枚引きます。

▼ おじさんの盆栽
縁側のおじさんが持つ盆栽を庭へ落とし、同じ盆栽どうしが触れるとくっついて1つ上の盆栽になる一人用の落ちものパズル。桜から始まって金の松まで11段。大きい盆栽ほど高得点で、上の点線より上に盆栽がとどまるとゲームオーバーです。

▼ サイコロ役づくり
サイコロ5個を1ターンに3回まで振り、残したい目をキープしながら12の役に1回ずつ点を入れていく一人用のダイスゲーム。サイコロは立体で転がります。1〜6の目の小計が63点以上ならボーナス+35点。12の役をぜんぶ埋めたら終わりで、合計点の自己ベストを目指します。

▼ おじさんちのねこさがし
おじさんの家の間取りに隠れた飼い猫を、推理で見つけていく一人用のパズル。部屋・行・列のそれぞれに猫がちょうど1匹ずついて、猫どうしはななめも含めて隣り合いません。盤は6×6・7×7・8×8の3段階で、答えは必ず1通りです。

【こんなときに】
・電車やバスでの移動中、電波が届かない場所で
・1日5分、頭の体操・脳トレに
・将棋やオセロを久しぶりに指したくなったときに
```
