## 1. タイトル（30字以内）

```text
あそびば：神経衰弱 マインスイーパー 五目並べ 将棋
```

**26/30字**。ブランド「あそびば」の維持は #32 の会長決裁（案A）どおり。

### なぜこの4語なのか（2026-08-13 に当番が iTunes Search API で再取得した実測）

上位5アプリの評価数は、そのキーワードで**新規参入が上位に食い込めるか**の代理指標になる（評価数が少ない＝ダウンロードも少ない＝抜きやすい）。
あそびばは**評価0件**なので、上位が万単位の語では構造的に勝てない。

| キーワード | 上位5アプリの評価数 | 判定 |
|---|---|---|
| **神経衰弱** | 993 / 578 / 881 / 51 / 759 | **全て1,000未満の無風地帯**。4位は評価51・最終更新2016年 |
| **マインスイーパー** | 24,262 / 3,554 / 3,539 / 1,234 / 2,410 | 1位以外は1〜3千台。**下位グループには入り得る** |
| **五目並べ** | 6,660 / 9,974 / 1,030 / 2,577 / 22,346※ | 1万未満に分散、寡占なし（※5位は別ジャンルの Tic Tac Toe） |
| 将棋 | 169,958 / 34,014 / 21,927 / 168 / 43,162 | 将皇・ぴよ将棋の寡占。**検索順位は狙わない** |
| オセロ | 106,394 / 168,232 / 17,742 / 1,834 / 10,440 | 同上 |
| 2048 | 7,410 / 54,520 / 1,561 / 14,790 / 560 | 同上 |

- どの語でも現在の掲載順位は**すべて圏外**（上位10件に自社なし）。失うものは無い。
- **将棋だけは順位を狙わずに残す**。人間が検索結果を見たときの「本格ゲームも入っている」という信頼の担保と、
  `将棋 神経衰弱` のような組み合わせ検索の受け皿にするため。順位で戦うのはあくまで前3語。
- Issue #91 本文の「マインスイーパー上位の多くが2018〜2020年更新のレガシー」は、**今回の再取得では確認できなかった**
  （上位5件の最終更新は2023-01〜2026-08）。ただし評価数の少なさという参入根拠のほうは再現したので、施策の結論は変えていない。

**数字だけ見れば `将棋`（中央値34,075）を降ろして `大富豪`（3,758）を上げるのが筋**で、実際 `大富豪` は
今回の候補中で `神経衰弱` に次いで良い。それでも**今回は据え置く**。理由は3つ:

1. **`将棋` は元から順位を狙っていない枠**（上の #91 の設計どおり、信頼の担保と組み合わせ検索の受け皿）。
   差し替えて得られるのは `大富豪` の順位可能性だが、`大富豪` は**キーワード欄に入れれば拾える**（§3 で追加済み）。
   失うのは「検索結果に将棋と書いてあることによる転換率」で、こちらは**評価0件・DL4 の現状では測定できない**。
   測れない side を捨てて測れない side を取る交換なので、実測を根拠にした差し替えにはならない。
2. **5語に増やす案（`…五目並べ 将棋 大富豪` = ちょうど30字）は採らない**。タイトルへのゲーム名列挙は
   ガイドライン 2.3.7（メタデータのキーワード詰め込み）の指摘対象になりうる構造で、
   **同じ構造の v1.1.0 タイトルが現在審査中・可否未確定**。会社全体のボトルネックが v1.1.0 の公開である以上、
   ここで審査リスクを積み増す判断はしない。
3. **フィールドを跨いだ重複は加点されない**（§3-1）。タイトルに `大富豪` を入れるなら §3 から外すことになり、
   本パックとキーワード欄の設計が連動して壊れる。片方だけ採用されると重複か欠落のどちらかが起きる。

**再検討の条件**（次にこの判断を見直すべきタイミング）: v1.1.0 または v1.1.1 が**審査を通過**し、かつ
#54（ASO 二巡目）の効果測定で `神経衰弱` / `マインスイーパー` / `五目並べ` の掲載順位が取れていないと分かったとき。
そのときは上の表を取り直したうえで `将棋` → `大富豪` の1語差し替え（27字）を第一候補とする。

### 審査上の注意

v1.1.0 のタイトルも同じ「ブランド名＋ゲーム名の列挙」構造で、**現在審査中＝可否は未確定**。

## 2. サブタイトル（30字以内）

```text
オフラインで遊べる定番10種｜勝手に出る全画面広告なし
```

**27/30字**（#178 で `定番8種` → `定番10種`。実装は10ゲーム = §5-d）。

- `オフライン` は競合の実証済み訴求（評価上位の詰め合わせ勢はほぼ全てが冒頭で訴求している）。
- `勝手に出る全画面広告なし` は §5-b で裏を取った事実。**修飾語の「勝手に出る」を必ず付ける**:
  リワード動画（`GADRewardedAd.present(fromRootViewController:)`）は**全画面広告そのもの**なので、
  「全画面広告ゼロ」と言い切ると虚偽になる。事実は「自動では出ない／出るのはユーザーが自分で選んだときだけ」。
- **「広告なし」とも書かない**（バナーは出るため。`広告なし` と書くと、その語で検索した人の期待とずれて
  低評価・返金の原因になる）。
- `詰め合わせ` はサブタイトルから外してキーワード欄へ移した（`ゲーム 詰め合わせ` は検索結果が4件しか無い
  超薄フィールドで、重み最上位の枠を使わなくても取れる）。

## 3. キーワードフィールド（100字以内・カンマ区切り・スペースなし）

```text

```

**97/100字・21語**（UTF-8 で243バイト）。**#178 で再設計した**（実測はすべて 2026-08-21 に取り直し・§5-f）。

### 3-0. この枠に何を置くかの原則（#178 で明文化）

日本ストアのキーワード枠は2つある（1枠目 = 日本語ロケール = **この欄**、2枠目 = 英語(U.S.) ロケール =
[`keywords-cross-localization-v1.1.1.md`](keywords-cross-localization-v1.1.1.md)）。この2枠は**性質が違う**:

| | 1枠目（この欄） | 2枠目 |
|---|---|---|
| 入稿できる条件 | **無条件**（今の構成のまま入る） | **#171 の ASC 操作（英語(U.S.) ロケールの追加）が済んで初めて生える** |
| 現在の状態 | 稼働中 | **未実現**（#171 は会長の ASC 報告待ちで `blocked`） |

→ **収録ゲームの正式名は必ず1枠目に置く。** 2枠目が生えなかった場合でも取りこぼさないため。
別名（`上海` `雀牌` `牌`）・一般語・属性語は2枠目に寄せる。この原則の適用が今回の主変更点で、
`大富豪` `麻雀ソリティア` を2枠目から1枠目へ移した。

### 3-1. 取捨選択の根拠

1. **タイトル・サブタイトルに入れた語は全て除外**（同じ語を複数フィールドに入れても加点されない）。
   v1.1.0 のキーワード欄にあった `五目並べ` `神経衰弱` はタイトルへ昇格したので、ここからは削除した。
2. **タイトルから降ろした語を回収**: `オセロ` `2048` `ポーカー` `ブラックジャック`。順位は狙えないが、
   `オセロ 無料` のような**組み合わせ検索の部品**として機能させる（この欄に無いと組み合わせも作れない）。
3. **別名の回収**: `リバーシ`（オセロ）・`連珠`（五目並べ）・`地雷`（マインスイーパー）。1語2〜4字と安い。
4. **`一人用` を新規追加**: 神経衰弱の競合2位が「神経衰弱　一人用」で、この語に実需がある。CPU対戦専用という
   あそびばの性質とも一致する。
5. **`日本製` を新規追加**: §5 で裏を取った訴求。説明文は検索対象外（下記の注）なので、検索面で効かせるには
   この欄に入れる必要がある。
6. **収録していないゲーム名は入れない**。誤誘導は審査指摘の対象。
   **`麻雀`（四人打ち）単体は今も不採用**（実装しているのは麻雀ソリティア = 牌を消すパズル。四人打ちは #106 で
   未実装・未決裁）。句としての `麻雀ソリティア` は**実装済みなので採用してよい**。
7. 他社アプリ名（将皇・ぴよ将棋など）は審査・法務リスクのため引き続き不採用。

日本語ロケールのタイトル・サブタイトル・キーワードの**どこにも入っていなかった**

### 3-4. `続きから` を2枠目から1枠目へ移した

`続きから` は**検索結果が4件しか無い超薄フィールド**（評価件数 1 / 7 / 121 / 1）で、
かつ「中断してもその場から再開できる」は**実装済みの差別化点**。§3-0 の原則どおり、
実測が最も良い語は不確実な2枠目ではなく**確実に入る1枠目**に置く。

> **注（本パックの前提）**: App Store の検索インデックスに載るのは **タイトル・サブタイトル・キーワード欄・
> デベロッパ名**で、**説明文は検索対象に含まれない**という一般的な理解に基づいて配分している
> （Apple はアルゴリズムを公開していないため、断定はできない）。説明文の役割は転換率であって順位ではない。

**字数の単位について**: この欄の上限は Apple の表記で「100 characters」、App Store Connect の入力欄も
**文字数**でカウントする（全角1字＝1カウント）前提で設計した。万一 ASC が上限超過を出したら、下のバイト数版
（94バイト・36字）に差し替えてほしい。

```text
大富豪,麻雀ソリティア,リバーシ,連珠,地雷,一人用,詰め合わせ,日本製
```

**削る優先順位は「他フィールドで拾える語 → 一般語 → 属性語」。ただし `大富豪` `麻雀ソリティア` は
最後まで残す**（#178。この2語だけは日本語ロケールのどのフィールドにも無く、落とすと収録ゲームが
2本まるごと検索面から消えるため）。残りは**タイトル・サブタイトルのどこにも無く、この欄でしか拾えない**語。

### 4-a. 冒頭3行（差し替え）

