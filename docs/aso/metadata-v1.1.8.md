### 0-1. 要確認: `App/AppGameServices.swift` の `GameRegistry` が機械的には 23 本を返す

`release/v1.1.8` の `GameRegistry` には柵越えおじさん（`HomerunModule()`）がコメントアウトされずに
含まれている（#1348・#1565 でハブに追加）。会長指示（2026-10-02・#1606 のコメント）により
「リリースノート・入稿パックに遊べないもの（柵越えおじさん関連）を一切載せない」方針のため、
本パックは柵越えおじさんを含めず収録本数を **22本のまま**にしている。

一方、`Scripts/check-aso-game-count.sh` は `GameRegistry` に並ぶ非コメントの `XxxModule()` を機械的に数えるだけで、
「ハブ非公開扱い」のような業務上の意味は分からない。実際に試した結果:

```
check-aso-game-count: 入稿パックの収録本数が実装と一致しません
  実装（App/AppGameServices.swift の GameRegistry）: 23本
  パック（本パックの入稿文言）                      : 22本
```

**入稿前に対応が必要**（このままでは `fastlane beta` 相当のチェックが落ちる可能性がある）。考えられる対応:
- `HomerunModule()` を出荷直前までコメントアウトしておく（企画倉庫の他ゲームと同じ扱いに戻す）
- または、入稿文言に柵越えおじさんを含めて 23 本として書き直す（ただし会長指示と矛盾するため不可）
- またはチェックスクリプト側で「マーケティング対象外」の除外リストを設ける

いずれを取るかは会長・社長の判断事項のため、本 PR では決めずに注記のみ残す。

・通知を開いたときにアプリが終了することがある不具合を直しました

### 5-1. 事実確認: しりとりの新モード名

`release/v1.1.8` の実装を確認したところ、**UI上の表示名は「とことん」であり、「とことんモード」という表記は
実装のどこにも無い**（コード内のコメント・テスト名でだけ開発者用語として「とことんモード」が使われている）。

- `Packages/GameKit/Sources/GameShiritori/ShiritoriRules.swift`:
  `ShiritoriMode.endless.label` は `"とことん"`（`.quota` は `"ノルマ"`）
- `Packages/GameKit/Sources/GameShiritori/ShiritoriView.swift`:
  モード選択のチューザー・ルールシートの見出しとも `"とことん"`
- `Packages/GameKit/Sources/Core/HowToPlay.swift`:
  遊び方ガイドでも `「とことん」はノルマが無く、...`

**要修正の可能性**: 新機能欄の「とことんモード」は、会長の確定文面としてそのまま掲載しているが、
実際の画面表示とは字面が異なる（「モード」が付かない）。表記を実装に合わせるか、このまま進めるかは
会長判断のため、本 PR では文面を変更せず、この注記のみ残す。
