# App Store カテゴリ変更（v1.1.11 提出時・日本ストア）

会長指示（2026-10-09・#1964）: 「1カード 2ボード 3パズル」。v1.1.11 の審査提出時に ASC のカテゴリを変える。
`metadata-v1.1.11.md` ではなくこの名前にしているのは、`Scripts/check-aso-game-count.sh` が
`metadata-vX.Y.Z.md` を収録本数の入稿パックと見なして検査するため（本ファイルはカテゴリ専用で本数を主張しない）。

## 1. 変更内容

| 項目 | 今（v1.1.0 パック §7 で設定） | v1.1.11 から |
|---|---|---|
| 主カテゴリ | ゲーム | ゲーム（そのまま） |
| ゲームの種類 1つ目 | ボード | **カード** |
| ゲームの種類 2つ目 | パズル | **ボード** |
| 副カテゴリ | エンターテインメント | エンターテインメント（そのまま） |

- ゲームの種類は 2 つまでしか選べない（ASC API の appInfos も `primarySubcategoryOne` / `primarySubcategoryTwo` の 2 枠）ため、
  3 番目の **パズルは外れる**。
- `metadata-v1.1.0.md` §7 の「ボード＋パズル」は v1.1.10 までの記録として残す。v1.1.5 / v1.1.1 / v1.1.3 パックの
  「カテゴリ（ボード＋パズル）は v1.1.0 §7 のまま」は **v1.1.11 から本ファイルが上書きする**。
