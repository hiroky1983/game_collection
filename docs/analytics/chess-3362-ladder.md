# チェス CPU の段階表の再調整（#3362）

会長決裁（2026-11-07・issue #3362「決定事項」）に沿って、入門・かんたん・ふつう を弱くし、初回の段を かんたん にした記録。
人の勝率（2026-10-20〜11-05・ストア版）が 入門 14%（3-18）・ふつう 0%（0-17）・むずかしい 0%（0-7）と強すぎたため。
前回 #1566（`docs/analytics/chess-1566-ladder.md`）の「隣の段に 60〜70%」の考え方は、人の勝率を目標にする方式に置き換わった
（出したあとの目標: 入門 60% 以上・かんたん 40〜60%・ふつう 35〜50%・むずかしい 20〜30%）。

## 条件

- 合否（会長決裁）。得点率 =（勝ち + 引き分け×0.5）÷ 全局数
  1. **今より弱い**: 新しい段 対 今の同じ段で、新しい段の得点率が **40% 以下**
  2. **段の並び**: 隣の段どうしで、上の段の得点率が **55〜75%**。ただし むずかしい は変えないので、ふつう 対 むずかしい は
     75% を超えても不合格にせず、超えたら会長に判断を仰ぐ
  3. **壊れていない**: 反則手 0・1 手の考える時間は最大 3 秒以内・既存のテストがすべて通る
- 1 組 200 局（開始局面 1〜100 × 先後入れ替え）。開始局面は全組で同じ（`CPUBenchLadder.opening`）
- 計測: `Scripts/chess-cpu-bench`（最適化ビルド）`NPS=100000 PLIES=300 CONCURRENCY=4`（#1462・#1566 と同じ）。考える時間は局面数（NPS × 秒）に置き換える
- 変えるもの: 入門・かんたん・ふつう の最善手を打つ確率と、入門の外したときの損の幅。考える時間・深さの上限（下の 3 段は 1 手先）・むずかしい は据え置き
- 「今の段」は、出荷の確率・損の幅を `match` の引数で指定して再現した（入門 `novice::350 0.6`・かんたん `easy 0.7`・ふつう `normal 0.8`。
  損の幅の差し替えのため、段階名の 3 つ目に `novice::350` のような損の幅の指定を足した）

## 変更前後の値

| 段階 | 考える時間 | 深さ上限 | 最善手の確率（前 → 後） | 外したときの損の幅（前 → 後） |
|---|---|---|---|---|
| むずかしい | 2 秒 | なし | 100%（変えない） | —（外さない） |
| ふつう | 0.5 秒 | 1 手先 | 80% → **50%** | 350 |
| かんたん | 0.1 秒 | 1 手先 | 70% → **40%** | 350 |
| 入門 | 0.02 秒 | 1 手先 | 60% → **55%** | 350 → **550** |

- 損の幅 350 = ナイト・ビショップ 1 枚ぶん（位置の点込み）までの損の手から選ぶ。550 = ルーク 1 枚ぶんまで（クイーンを只で失う手は入らない）。
  「入門は駒をただで取られるミスも許す」（社長の叩き台）を、入門だけ幅を広げる形で入れた
- 入門の確率（55%）が かんたん（40%）より高いのは、入門の外しが大きい（ルークまで只で取られる）ため。幅 550 のまま確率を
  かんたん と同じくらいまで下げると、かんたん 対 入門 が 75% を超える（下の探索の表）

## 探索（100 局・開始局面 1〜50 × 先後・叩き台の確かめと値の絞り込み）

叩き台（入門 20%・かんたん 40%・ふつう 60%・入門の損の幅を大きく）から始めて測った。

| 組 | 上の得点率 | 読み取り |
|---|---|---|
| 入門 20%・幅 350 対 今の入門 | 7.5% | 叩き台の入門は今の入門より大きく弱い |
| 入門 50%・幅 350 対 今の入門 | 41.5% | 幅 350 のままだと 50% で「40% 以下」の境目 |
| 入門 40%・幅 600 対 今の入門 | 5.0% | 幅を広げると確率以上に効く |
| かんたん 40% 対 入門 20%・幅 550 | 95.5% | 叩き台どおりだと かんたん と 入門 の差が開きすぎる |
| かんたん 40% 対 入門 30%・幅 550 | 92.5% | 同上 |
| かんたん 40% 対 入門 40%・幅 550 | 84.5% | 同上 |
| かんたん 40% 対 入門 50%・幅 550 | 73.5% | 帯の上の端 |
| かんたん 40% 対 入門 55%・幅 550 | 64.5% | 帯の中ほど（採用） |
| かんたん 40% 対 入門 60%・幅 550 | 54.0% | 帯の下に外れる |
| かんたん 40% 対 入門 30%・幅 350 | 67.0% | 幅を広げない案（叩き台の「ただで取られるミス」を入れないので採らない） |

| ふつう 60% 対 今の ふつう | 28.5% | |

- ふつう は 60% でも基準を満たすが、人の勝率がふつうで 0%（0-17）と最も目標（35〜50%）から遠いので、低い方の 50% を採った
