# #192 大富豪: 開幕の全画面モーダルを他ゲームと揃える — 画面確認

撮影環境: **iPhone 17 Pro Max（440×956pt・@3x）**・Debug ビルド・`-screenshotMode`
（広告を出さず ATT も聞かない）・`-startGame daifugo`。

**撮り方**: 中断スナップショットは**注入していない**（本件で見たいのが「セーブが無い初回起動」
そのものであるため）。同じ手順を `release/v1.1.3` の HEAD（553075d）と本 PR でそれぞれ
ビルドして撮り、並べた。

## before-after.jpg — 変更前後

| 面 | 内容 |
|---|---|
| 左 | **変更前**。盤が一切見えないまま `DaifugoStartSheet`（`.presentationDetents([.large])` かつ `.interactiveDismissDisabled(true)`）が全画面を覆い、「ゲーム開始」を押すまで遊べない |
| 右 | **変更後**。カードが配られた盤がそのまま出て、すぐ「あなたの番」から遊べる |

変更後の画面で受け入れ条件を満たしていることが読み取れる点:

- **`?` ボタンがツールバー右にある**（「投了」の左）。`.howToPlay(.daifugo) { DaifugoRuleSheet() }`
  は変更前から付いていたが、モーダルに隠れて初回には見えていなかった。
- **初回ミニガイド「場より強い組を出そう」が手札の下に出ている**。これも `HowToPlayHint` は
  変更前から置かれていたが、初回はモーダルの裏で「表示済み」フラグだけ消費されており、
  実際にはユーザーの目に触れていなかった（`HowToPlayHint.init` が `markGuideShown` を呼ぶため）。
  モーダルを外したことで、意図どおり初回に1回だけ見える。
- **セーブが無い状態でそのまま遊び始められている**（1ゲーム目・手札14枚・「あなたの番」）。

## 情報の引き継ぎ

廃止したモーダルの「ゲームの流れ」4項目の行き先:

| モーダルの項目 | 移設先 |
|---|---|
| CPU3人と対戦。手札を早く出し切るほど上の階級 | **`DaifugoRuleSheet` に「ゲームの流れ」を新設**（本 PR で追加） |
| 場と同じ枚数で、より強い組だけ出せる | `DaifugoRuleSheet`「出し方」（既存） |
| 出せない・出したくないときはパス | `HowToPlayGuide.daifugo` の2行目（既存・`?` シートの本文） |
| 決着後は階級に応じてカードを交換して次戦へ | `DaifugoRuleSheet`「階級とカード交換」（既存）と、リザルトカード下部の但し書き（既存） |

`DaifugoRuleSheet` へは `?` → 「くわしいルール」で到達する（変更前はモーダルの
「ルールを見る」からも到達できたが、遷移先は同じ `DaifugoRuleSheet`）。
