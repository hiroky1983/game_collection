# #193 大富豪: 余白・場の出し手・直近アクションの保持 — 画面確認

撮影環境: **iPhone 17 Pro（402×874pt・@3x）** と **iPhone SE 第3世代（375×667pt・@2x）**・
Debug ビルド・`-screenshotMode`（広告を出さず ATT も聞かない）。

**撮り方**: シミュレータはタップ操作を自動化できないため、大富豪の中断スナップショットを
アプリのコンテナへ注入し `-startGame daifugo` でその画面を直接開いている。

- **対局中**: 3ゲーム目・場に CPU2 の Q Q・人間の手番・手札9枚。
  スナップショットには `lastActions`（CPU1 パス / CPU2 「Q Q」/ CPU3 パス）を入れてある。
- **リザルト**: 人間だけ上がり済みで CPU が1枚ずつ残る局面を注入し、
  起動直後の CPU 自動消化でそのまま決着させている。

before は同じスナップショットを `release/v1.1.3` の HEAD でビルドして撮った。

## 01-playing-before-after.jpg — 対局中（iPhone 17 Pro）

| 受け入れ条件 | 見え方 |
|---|---|
| 場と手札の間の空白が半分以下 | 背景色の帯を実測して **131pt → 0pt**（場のカードが余りを吸って手札に接する） |
| 場のカードに出し手が分かる表示 | 場の見出しが「場」→ **「CPU2 が出した」バッジ**（自分が出したときは person アイコン + teal） |
| 中断復帰後も直近の動きが残る | before は CPU の帯が**空**（`lastActions` を保存していないため復帰で消えていた）、after は **パス / Q Q / パス** が復元されている |

- 背景の空白を 0 にしたのは `Spacer` をやめて**場のカード自身**に縦の余りを吸わせたため。
  `Spacer` に吸わせると同じ量がそのまま背景色の穴として残る。

## 02-result-before-after.jpg — リザルト（iPhone 17 Pro）

- リザルト下の背景空白は **174pt → 0pt**。リザルトのカードが余りを吸って「次のゲーム」まで届く。
- カード内では「今回の結果」（見出し・順位表）を上、「この先」（通算成績・次ゲームの案内）を下に置き、
  伸びた分は2つの塊の**間**に集めている。カード全体を中央寄せにすると見出しが画面の真ん中まで
  降りてきてしまうため。
- 注: before の画像には「次はこれで遊ぶ？ ポーカー」のレコメンド枠が写っている（表示条件が
  確率的なため after には出ていない）。この枠は「次のゲーム」ボタンより**下**にあるので、
  上で測った空白の値には影響しない。枠が出ないぶん before の空白は実際にはもう少し広くなる。

## 03-iphone-se.jpg — iPhone SE 第3世代（375pt）

対応端末の中で最も狭い 375pt でもレイアウトが崩れないことの確認（受け入れ条件の4つ目）。

- 対局中: 場のカードが縮み、出し手バッジ・場のカード・手札7列がすべて収まっている。
- リザルト: 順位表と通算成績・次ゲームの案内が重ならずに収まっている。
- 対局中の画面でカードが暗く「出せる組がありません」が出ているのは、この端末の設定で
  ヒント表示（#190）が ON になっているため。本 PR の変更とは無関係。
