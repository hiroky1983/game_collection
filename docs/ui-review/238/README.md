# #238 麻雀ソリティアの「くわしいルール」 — 画面確認

`feat/mahjong-detailed-rules-238` の実測（iPhone 17 Pro Max・iOS 26.5・Debug + `-screenshotMode`）。

シート内の画面はシミュレータのタップでは開けないため、**一時的なプローブビルド**（`GameCollectionApp`
の DEBUG 分岐から `HowToPlaySheet` / `MahjongSolitaireRuleSheet` を直接根に置く起動引数を足したもの）で
撮影した。プローブの差分はコミットしていない（`git checkout -- App Packages` で破棄済み）。

## 画像

| ファイル | 内容 |
|---|---|
| `howto-and-rules.jpg` | 左: `?` から開く「遊び方」シート（`くわしいルール` の行が増えている）／右: そこから開く詳細ページ |

## 確認できること

- **導線**: 「遊び方」シートの 3 行の下に `くわしいルール` の行が出る。大富豪・四人打ち麻雀と同じ
  `HowToPlaySheet` の `extra` なので、見た目も遷移も既存 2 本とそろっている。
- **受け入れ条件の中身**: 「花牌と季節牌」の項に **梅・蘭・菊・竹どうし、春・夏・秋・冬どうしは
  絵柄が違っても合う**ことが書かれている。「取れる牌」の項に、上に牌が載っておらず左右どちらかが
  空いている牌だけを取れることが書かれている。
- **変えていないもの**: 3 行のルールと初回ミニガイド（`同じ牌を 2 枚タップで消そう`）は左の画像の
  とおり従来のまま。詳細を持つゲームのシートは `.presentationDetents([.large])` になるため、
  シート自体は最初から全画面で開く（既存の大富豪・麻雀と同じ挙動）。

## 文言と実装の同期

詳細ページの文言は `MahjongSolitaireRuleSheetTests` が検証している。文字列の有無を見るだけでなく、
**書いてある内容が実装と一致すること**（`MahjongFace.flower(0).matches(.flower(3))` が true、
`characters(1)` と `characters(2)` は false、`layout.count == 144` と内訳）も同じスイートで固定した。
花牌の説明から「絵柄が違っても」を削る／`.howToPlay` を extra 無しに戻す／枚数の表記を変える、の
3 通りの改変で**実際に赤くなることを実測**している。
