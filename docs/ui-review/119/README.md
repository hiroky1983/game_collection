# #119 ハブの2列グリッド化 — 変更前後の比較

撮影は `-screenshotMode`（広告なし・ATT なし）でシミュレータから取得。
記録（#115）の 1 行が出る様子を見せるため、`playLog_records_v1` にデモの記録を、
`Snapshots/` に 2048・オセロの中断データを注入してから起動している。

| ファイル | 内容 |
|---|---|
| `17pro-before-after.jpg` | iPhone 17 Pro（標準サイズ）。左が変更前（縦リスト・5枚しか見えない）、右が変更後（2列・全10ゲームがスクロールなしで収まる） |
| `se-before-after.jpg` | iPhone SE (3rd gen)。小画面でも2列を維持し、レイアウトは破綻しない（10枚は収まらず最後の1行だけスクロール） |
| `ipad-and-settings.jpg` | 左: iPad Pro 11（iPhone 互換モード）。右: 並び替え・非表示を設定した状態（麻雀ソリティア先頭の並び順 + 将棋・ポーカーを非表示 = 8枚） |

このアプリの `TARGETED_DEVICE_FAMILY` は `1`（iPhone のみ）のため、iPad では
iPhone 互換モードで動作する。iPad の確認はその前提で行っている。

バナー枠（`BannerSlot`・高さ 50pt）は広告の有無にかかわらず常に確保されるため、
撮影モードでも実機と同じ縦の余白で「1 画面に収まるか」を判定できる。
