# #198 麻雀ソリティア: アンドゥ（1手戻す）

撮影日 2026-08-24 / iPhone 17 Pro (iOS 26.5)・iPhone SE (3rd gen)・Debug ビルド `-screenshotMode`。

シミュレータは自動タップができないため、「取った直後」「手詰まり」「クリア後」の状態は
**撮影用の使い捨てビルド**（起動引数で盤面と操作を再現するだけの DEBUG コード）で作った。
撮影後にそのコードは削除しており、PR には含まれない。表示している画面そのものは本実装のもの。

| ファイル | 内容 |
|---|---|
| `01-controls.jpg` | プレイ中の操作バー。「戻す」が押せる状態（取った直後） |
| `02-deadlock.jpg` | 手詰まりオーバーレイ。「直前の1手を戻す」が並ぶ |
| `03-result.jpg` | クリア後のリザルト。「ヒント1回 / 並べ替え0回 / 戻す0回」 |
| `04-large-text.jpg` | 文字サイズ アクセシビリティ XXXL。アイコンのみの段に切り替わる（44pt 以上を確保。「戻す」は取る前なので押せない表示） |
| `05-iphone-se.jpg` | iPhone SE（375pt）。3ボタンが1段に収まる。「戻す」は取る前なので押せない表示 |

## レイアウトで直したこと

ボタンが3つになった時点で、**既定の文字サイズでも**文字が2行に折り返し、
右端に出していた利用回数（「ヒント1 / 並べ替え…」）が切れた（iPhone 17 Pro で実測）。

1. プレイ中の利用回数表示をやめた。回数はクリア後のリザルトに3つとも（0回も省かず）出すので、
   情報は失われない。
2. 文字が大きい設定では `ViewThatFits` でアイコンのみの段に落とす。縮小（`minimumScaleFactor`）に
   頼る案も試したが、アクセシビリティ XXXL では 0.5 まで許しても「ヒ…」と切れて、
   大きいアイコンより読めなかった。
