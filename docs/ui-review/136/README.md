# #136 マインスイーパーのステータスバー — 変更前後の比較

撮影は iPhone 17 / iOS 26.5 シミュレータ。難易度ごとの盤面と最悪値（残り地雷数・タイム）を
再現するため、`Library/Application Support/Snapshots/minesweeper.json` に中断データを
注入してから `-startGame minesweeper` で起動している。

| ファイル | 内容 |
|---|---|
| `hard-before-after.jpg` | 上級（15×15・残り40）でタイム `999` の状態。上が変更前で `999` が「99 / 9」の 2 行に折り返している。下が変更後で 1 行に収まり、状態絵文字もバー中央に来る |
| `after-all-cases.jpg` | 変更後の初級（9×9・残り10）・中級（12×12・残り25）・上級＋ズーム ON（残り40・タイム999）。いずれも 1 行に収まる |

ズーム ON の状態はタップ操作ができないため、`zoomMode` の初期値を一時的に `true` にした
ビルドで撮影している（この変更はコミットしていない）。

バナー枠に出ている「Test mode」は AdMob のシミュレータ用テスト広告で、実機の表示とは無関係。
