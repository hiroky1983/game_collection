# #137 神経衰弱: ミスマッチ後の自動ターン交代

`auto-turn-flow.jpg` — 人間がミスマッチしてから CPU の手番を経て自分の番に戻るまで。
一切タップせずに進んでいる（③まで無操作）。

| コマ | 状態 | 見どころ |
|---|---|---|
| ① | ミスマッチ直後（猶予 1.2 秒） | 「次へ」ボタンが無い。「待った」が有効（紫）で、右側に「ミスマッチ… 待ったは今だけ」が出る |
| ② | 猶予を過ぎて自動で裏返った直後 | CPU チップがコーラルに反転しスピナーが回る。CPU が1枚めくっている（🍇） |
| ③ | CPU の手番が終わった後 | 自分の番に戻り「待った」は無効に戻る |

## 撮り方（再現手順）

シミュレータへのタップ操作は当環境では自動化できない（アクセシビリティ権限が要る）ため、
`Scripts/capture-aso-screenshots.sh` と同じスナップショット注入方式で撮影した。

1. `xcodegen generate` → Debug ビルド（`-screenshotMode` で広告と ATT を止める）
2. `Scripts/aso-demo-snapshots.py` の `concentration.json` をアプリのコンテナへ配置
3. `-startGame concentration` で神経衰弱を直接開く
4. ミスマッチ状態そのものはスナップショットに含まれない仕様（復元時に裏返す）ため、
   撮影時だけ「起動直後に2枚をミスマッチ状態にする」一時フックを当てたビルドで撮影した。
   **このフックはコミットしていない**（撮影後に `git checkout` で破棄）。②③ の自動交代は
   製品コードの `scheduleAutoClear()` がそのまま動いた結果。
