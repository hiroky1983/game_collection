# #203 マインスイーパー: 連鎖開放の演出とタップ標的（撮影記録）

撮影環境: iPhone 17（iOS 26.5 シミュレータ）・Debug ビルド・`-screenshotMode`（広告なし）。
盤面はスナップショット注入で用意し、シミュレータへのタップ操作は使っていない
（この環境ではタップの自動化ができないため）。

## cascade-strip.jpg — 連鎖開放の演出

9×9・地雷5個（下2段のみ）の盤で左上 (0,0) を開けたときの連鎖を 30fps で録画し、
0.1 秒おきのコマを並べたもの。

- タップ地点から**波状に広がって**開いていくのが見える（従来は全マスが同時に切り替わっていた）
- 開ききるまで **約 0.4 秒**。`MinesweeperMetrics.revealDelay(forWave:)` の上限（0.35 秒）+
  1 マスぶんの長さ（0.16 秒）が上限で、盤が大きくなっても伸び続けない
- 録画のために `-simulateCascade` という一時的な DEBUG プローブ（2.5 秒後に (0,0) を開く）を
  当てたビルドを使った。**このプローブはコミットしていない**

## statusbar-compare.jpg / full-compare.jpg — タップ標的 44pt

- 旗・拡大の切り替えが 29×23pt → **44×44pt**。アイコンの間隔が広がっているのが見て取れる
  （実測の中心間距離: 39.3pt → 52.3pt = 44 + HStack の spacing 8）
- ステータスバーの上下余白を 8 → 4 に詰めたため、**盤面の高さは 369.7pt で前後とも同一**
  （盤の位置が 2.3pt 下がるだけ。#148 で捻出した高さを食っていない）
- タイマーの数字が前後で違うのは、起動からの経過秒がコマごとにずれるため（撮影上のノイズ）
