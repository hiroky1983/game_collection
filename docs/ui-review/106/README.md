# #106 四人打ち麻雀（東風戦・CPU3人）の画面

撮影: iPhone 17 Pro / iOS 26.4・Debug ビルド `-screenshotMode`（広告なし）。

| ファイル | 画面 |
|---|---|
| `01-play.jpg` | 対局中（東2局1本場・自分が親で聴牌・CPU2 が立直） |
| `02-hand-result.jpg` | 局の決着（CPU1 のツモ和了・役と点数の内訳） |
| `03-start-sheet.jpg` | 開始シート（この版の範囲を明記） |
| `04-hub.jpg` | ハブ（新しい「麻雀」カード。並び順は撮影のためだけに入れ替えている） |

## 撮り方

シミュレータへのタップ操作は使えないため、他ゲームの ASO 撮影
（`Scripts/capture-aso-screenshots.sh` / `Scripts/aso-demo-snapshots.py`）と同じ手口で、
`MahjongSnapshot` と同じ形の JSON をアプリのコンテナへ置き、`-startGame mahjong4` で
局面から直接開いている。

- `01` は自分の手番の局面をそのまま注入したもの。
- `02` は **CPU1 の手番 + ツモ和了できるツモ牌**を注入し、画面を開いた時点で CPU が和了する状態にした
  （`.task(id:)` が CPU の手番を進めるので、タップ無しで決着まで届く）。
- `04` はハブの並び順（`gameOrder_v1`）をシミュレータ側の `defaults` だけで入れ替えて、
  11 本目のカードを画面内に入れている。**アプリの既定の並び順は変更していない**（登録は末尾）。

ASO 用スクリーンショットの撮り直しは #184 の担当。
