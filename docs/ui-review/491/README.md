# #491 ソリティアの詰み告知を閉じられるようにする

`iPhone 17 Pro Max`（1320×2868）で撮影。ビルドはどちらも Debug・`-screenshotMode`。
before は `origin/release/v1.1.3`（`f4608bf`）を別 worktree に展開して同じ手順でビルドしたもので、
**両方に同じ中断データ（`solitaire.json`）を注入して**同一局面を撮っている
（33 手・6:16 の表示が一致していることで確認できる）。

- `deadend-prompt.jpg` — 詰み告知（`isDeadEnd`）の before / after

## 撮影に使った局面

`seed 34` を 125 手（うち山めくり以外 33 手）進めた行き止まり。**盤には K♥ の列と空列が2本見えており、
「K を空列へ移す」合法手は残っている**（`hasProgressMove` はこれを「列を入れ替えるだけ」として
数えないため `isDeadEnd` が立つ）。#475 の会長QAで報告された「指せる手が見えているのに触れない」
状況そのもので、この局面を選んだのはそれが理由。

中断データは `SolitaireSolver.successors` を使ったランダムプレイアウトで探索して作った
（探索コードは撮影用の一時ファイルで、PR には含めていない）。
