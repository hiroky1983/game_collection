**前提の変化1: SE 固有ではなくなった。** 決裁スレッドの表は「17 Pro は牌を縮めれば機械的に
解ける／SE だけ 50pt 足りない」としていたが、現 HEAD では 17 Pro でも同じ重なりが出る。
`t = side/19` として卓が要求する高さを積むと `188 + 10.72t` に対し使えるのは `19t` で、
収まる条件は `side ≥ 431pt`。17 Pro の卓は約 367pt なので約 28pt 足りない（SE はさらに不足）。

**前提の変化2: #263（鳴き）が入って要素が増えた。** 決裁の A/B/C は副露が無い時代の
選択肢で、副露が2組以上ある局面はどれを選んでも救えない（下記）。

### 選択肢の効きを一時ビルドで実測した

- **`LazyVGrid` の高さ過少申告ではない**（当番の仮説は外れ）。`discardStrip` を素の
  `VStack`+`HStack` に置き換えても重なりは1ピクセルも変わらなかった。**素直に場所が足りていない**。
- **B のみ**（左右の河を4段→2段 = 表示8枚→4枚）: 左右のチップの重なりは解消するが、
  **自分の段が残る**（名前チップに河の1段目が乗り、河の2段目が手牌の縮小一覧に隠れる）。
- **A + B**（手牌の縮小一覧を出さない + 左右の河を2段）: **副露1組までは SE・17 Pro とも完全に収まる**。
  副露2組で自分の副露と河が再び重なり、4組では卓外へ切れる。
- **C（中央パネルを出さない）は高さに効かない**。中央パネルは左右の列と同じ行に居るので、
  外しても行の高さ（= 左右の列の高さ）が縮まない。決裁の推奨 A+C は、実測では A+B であるべき。

したがって当番の推奨は **A+B に加えて、副露の表示自体にも上限か圧縮が要る**。決裁の
選択肢に無い項目なので、決裁スレッドを更新して再掲した。
