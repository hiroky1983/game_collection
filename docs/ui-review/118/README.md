# #118 「遊び方」導線の統一 — 画面の証跡

撮影は iPhone 17 Pro（iOS 26）、`-screenshotMode`（広告なし・ATT なし）で
シミュレータから取得。ステータスバーは 9:41 に固定。

| ファイル | 内容 |
|---|---|
| `games-1.jpg` | 2048 / 将棋 / 五目並べ / マインスイーパー / オセロ |
| `games-2.jpg` | ポーカー / 神経衰弱 / ブラックジャック / 大富豪 / 麻雀ソリティア |
| `sheets.jpg` | `?` から開く遊び方シート（3行の要点・ポーカーは「くわしいルール」付き） |

`games-*.jpg` はどれも **初回プレイ時**の状態で、ツールバーの `?` ボタンと、盤の近くの
1 行ミニガイドの両方が写っている。ミニガイドはただのテキスト（`allowsHitTesting(false)`）で
モーダルではないため、後ろの盤やボタンはそのまま操作できる。

`sheets.jpg` の 2048 は `.presentationDetents([.medium, .large])` により半分の高さで開き、
シートの後ろに盤が見えている。ポーカー・大富豪だけは詳細ページを持つため最初から全画面。

## 撮り方（再現手順）

シミュレータへのタップ操作は使えないため、`Scripts/capture-aso-screenshots.sh` と同じ方式
（デモ用スナップショットをアプリのコンテナへ置いてから `-startGame <id>` で直接開く）で撮っている。
`sheets.jpg` と大富豪の盤面だけは、シートを開いた状態／開始シートを飛ばした状態を撮るために
一時的なローカル改変を当てて撮影し、**その改変はコミットに含めていない**（当番セッション内で戻した）。
