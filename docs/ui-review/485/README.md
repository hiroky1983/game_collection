# #485 iPad の縦の余白（ハブ・ポーカー）

`iPad Pro 13-inch (M5)`（2064×2752）と `iPhone 17 Pro Max`（1320×2868）で、
`Scripts/capture-aso-screenshots.sh` により撮影。ビルドはどちらも Debug・`-screenshotMode`。

## 実測（下端から続く「地の色だけの行」の割合）

| 画面 | before（`6144a06`） | after |
|---|---|---|
| `01-hub` | 53.1%（1460px / 2752px） | **7.1%**（196px） |
| `07-poker` | 45.1%（1242px） | **7.6%**（208px） |
| `10-settings` | 22.3% | 7.2%（設定シートの背後にハブが写るため連動して改善） |
| その他 7 枚 | — | 変化なし（ピクセル差 0） |

測り方は Issue 本文と同じ定義。ディスプレイの角丸とホームインジケータは UI の部品ではないので
数えから除いている（左右 60px と最下部 40px の中央帯）。

## iPhone が動いていないことの裏取り

base（`6144a06`）を別ワークツリーでビルドし、**同じシミュレータでアプリを uninstall してから**
10 枚ずつ撮って比較した（install 状態を揃えないと初回ガイドの有無で差が出る）。

- 10 枚中 9 枚が**ピクセル差 0**
- 残る `10-settings` は 70px（0.002%・「完了」ボタンのすりガラスのアンチエイリアス）。
  拡大して目視でも差は見えない
