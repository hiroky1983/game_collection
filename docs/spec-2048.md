# 2048 仕様

## 概要

4×4 のタイルを上下左右にスワイプして同じ数字を合体させ、2048 を目指すパズルゲーム。ソロプレイ。

---

## ゲームルール

- スワイプで全タイルが同方向に動く
- 同じ数字のタイルが隣接すると合体してその数字の 2 倍になる
- 毎ターン終了後にランダムな空きマスに「2」または「4」が出現
- 2048 のタイルを作るとクリア。「続ける / もう一度」の選択オーバーレイが出て、続けるとそのまま
  盤面を保って続行できる（#438。局は決着として記録し、続行は次の1プレイとして数え直す）
- 盤面が埋まって動けなくなるとゲームオーバー

---

## 操作

- 上下左右スワイプ → その方向にタイルを動かす

---

## UI

- 4×4 グリッド
- 各タイルは数字の値によって色が変わる
- スコア / ハイスコア表示
- 新規ゲームボタン

---

## コンティニュー（`RewardedRescue`・purpose: `continue`）

- ゲームオーバー時にリワード広告を視聴すると、盤面・スコアを保ったまま再開できる
- **1局につき1回のみ**（`continueUsed` フラグで管理。スナップショットに永続化するため、
  アプリを再起動してもコンティニュー権は復活しない）
- 終局時点で盤面は必ず全埋まりのため、そのままでは新タイルを置く空きマスが無い。
  最も値の低いタイルから**空きマスが4つになるまで**消して確実に続行できる状態にする
  （`Board.revive`。最高値のタイルは消さない）。新タイルは置かない
- リワード広告なので**視聴完了したときだけ**適用される（`RewardedRescue` 共通の局ガード・
  失敗アラート付き）

---

## 永続化

スナップショットで途中状態を保存。アプリ再起動後も続きから再開可能。
`continueUsed` / 2048到達済みフラグ（`hasWon`）/ 続ける選択オーバーレイの表示状態
（`showWinPrompt`）もスナップショットに含め、再起動をまたいでも状態が壊れないようにしている。
